## Mike Draugelis 

I build tools for evaluating AI in healthcare — with a focus on the gap between
"the model looks good" and "the intervention actually helped patients."

### 🏥 What I'm working on

**[healthcare-sim-sdk](https://github.com/Mdraugelis/healthcare-sim-sdk)** — a
Python SDK for simulating predictive-model deployments in clinical operations.
When you deploy an ML model into care, you never observe the counterfactual. This
SDK gives you a controlled environment with known ground truth so you can ask:
*How good does the model need to be? How many resources will the intervention
consume? What would have happened without it?* Includes validated replications
(Chong, Rosen, TREWS), CITS/ITS analysis, Platt-scaled controlled models, and a
30-paper audit reconciled with baseline detection methods.
